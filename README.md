# OLA Booking Analysis

## Project Overview

This project analyzes 103,024 OLA ride bookings using SQL and Power BI to identify trends in revenue, cancellations, customer behavior, payment methods, and operational efficiency.

## Tools Used

- Excel
- SQL
- Power BI

## Key KPIs

- Total Bookings
- Revenue
- Success Rate
- Driver Rating
- Customer Cancellations
- Driver Cancellations

## Analysis Performed

- Revenue Analysis
- Booking Status Analysis
- Cancellation Analysis
- Payment Method Analysis
- Operational Insights

## Key Findings

- Successful rides accounted for 62.1% of total bookings.
- Driver cancellations exceeded customer cancellations.
- Cash remained the dominant payment method.
- Driver not found was a major cause of failed bookings.
